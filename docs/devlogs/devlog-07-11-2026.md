## Devlog - 07/11/2026 – Additional Project Structure + Think through.

### Progress?

In my previous devlog, I was focused on implementing a CSV parser.
Whilst thinking through the design choices, I started to 
think about how beneficial custom parser could be, as well 
as the overall goal of this module; data ingestion and 
processing.

Rather than a custom parser, I want to focus on 
implementing something that would be more useful day to 
day with financial data. So I came up with the idea:
- Ingestor module - this will load and populate objects 
  with Trade data. Yet to decide whether this is a simple 
  struct or a more complex object. Decoder will be renamed.
- Validation - this will be responsible for checking 
  records: sequence gaps, timestamps going backwards, invalid values; report breaks
- Aggregation - this will be responsible for building bars 
  (OHLCV), VWAP, buy/sell volume from validated records.
- Bench - this will be responsible for benchmarking the 
  performance of the ingestor, validation and aggregation 
  modules.

So these are our immediate goals. Next steps will be to 
implement the ingestor module and start working on the 
validation module. I think this is a more fruitful plan and 
actually showcases something.
