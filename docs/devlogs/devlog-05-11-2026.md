## Devlog - 05/11/2026 – Implementing the CSV Parser

### Learnings - Part 1 Review, plans and thoughts:

In a previous devlog I had planned to:

- Finish the implementation of the `csv_reader` and add
  unit tests. Basically empty with one function and a
  bunch of scaffolding. The implementation will need error handling for file
  opening and reading. As well as error handling for
  parsing the csv data.

- Extend the csv reader to support other delimiters and
  data types; will be done using templates.

The actual goal of implementing the parser can be 
thought of as series of steps:
- We want to be able to open and read a CSV file.
- We want to be able to parse the CSV data. And perhaps 
  write back to that CSV file in line, or a new one. 
- We want to be able to support other delimiters and 
  data types. (This will be done using templates.)

- We will start by implementing a basic version of the 
  Parser. It will only handle a single delimiter and 
  data type (which in this case is to handle our known 
  file).
